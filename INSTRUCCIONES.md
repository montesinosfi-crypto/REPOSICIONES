# Instrucciones rápidas

## Actualizar existencias diarias
1. Descarga tu CSV de existencias.
2. Renómbralo a `existencias.csv`.
3. Súbelo a GitHub (misma carpeta que `app.py`).
4. Commit + push. Render se actualiza.

## Vistas importantes
- **Agrupada por producto**: imagen + todas las variantes (color/talla).
- **ALERTA: No visible en web pero sí en CEDIS**: lo que hay que traspasar.
